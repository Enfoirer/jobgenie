# JG-NNN Delivery title

- Implementation commit: actual full SHA and link, or explicitly pending.
- Actual development/completion date: record truthfully.
- Preparation date and timezone: record truthfully; label retrospective entries.
- Translation date, if applicable: distinguish translation from original preparation.

## Requirements and key decisions

Problem, scope, acceptance criteria, changed requirements, chosen approach and reason. Identify the requirement source without inventing original message times.

## Tests and builds

Actual commands, environment, log links, run time and results. Distinguish initial failure, corrected rerun, skipped tests and historical citations. Explicitly state missing or unrun checks.

## Screenshots or API examples

Capture/recording/sanitized API links, code revision, collection date, environment and data source. If inapplicable, state why.

## Deployment observations

Verified GitHub SHA, platform, observation time, status and deployment URL. State whether deployment was absent, checks unavailable or only native compilation was verified. Record signing and TestFlight separately.

## Boundaries and follow-up

Unverified behavior or remaining work. Do not infer personal hours, customers or revenue.
