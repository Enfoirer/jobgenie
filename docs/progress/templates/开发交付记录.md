# JG-编号 交付标题

- 实现提交：填写实际完整 SHA 和链接；未提交时标明待补。
- 实际开发/完成日期：据实填写。
- 本记录填写日期与时区：据实填写；历史回顾要注明补录。

## 需求与关键决策

问题与范围、验收标准、需求调整、实际采用方案及理由。注明需求来源；不填写无法核实的原始消息时间。

## 测试与构建记录

实际命令、环境、日志链接、运行时间和结果。区分首次失败、修复后结果、跳过项目与引用历史说明。未运行或缺失就明确记录。

## 成果画面或接口示例

截图/录屏/脱敏请求响应链接、对应代码版本、采集日期、环境和数据来源。无相关内容则明确“不适用”及原因。

## 部署记录

GitHub 远端 SHA、平台、查询时间、状态与部署 URL。没有部署、无平台检查或原生仅编译等情况如实标明。签名和 TestFlight 状态单独记录。

## 边界与后续

尚未验证或需要后续工作的事项。不得代填本人工时、客户活动或收入。
