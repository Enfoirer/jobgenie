# JG-030 Web first-use onboarding

Implementation and local acceptance completed on 2026-11-20 (Asia/Shanghai). Implementation revision [86189fd](https://github.com/Enfoirer/jobgenie/commit/86189fd19d8f4c20437d435453acb7cf1d626e8b).

## Requirements and key decisions

The owner selected web onboarding first. Add an English three-step guide for application tracking, calendar reminders and linked documents. Show it automatically on the Job Board for authenticated accounts with no saved applications and no terminal guide choice. Existing archived applications also suppress it. Defer while another dialog, busy state or focused form field is present. Step navigation stays within the guide and its final button opens the existing Add Job page.

Skip, the close button, backdrop dismissal and Escape record a skipped outcome. The final action records completion before navigating. Account persistence uses a live authenticated user, explicit response fields, same-origin JSON writes, bounded input and rate limits. The first terminal database write wins and retries preserve its timestamp. Existing accounts need no migration. Read [behavior and acceptance](../../web-onboarding-acceptance.md).

Dismiss immediately and queue an account-scoped local choice if persistence fails. Retry explicitly or on reconnection/focus/visibility. Stale replies and account changes cannot reopen a handled guide. Other devices suppress it after an account write succeeds and they refresh. During an outage, local persistence depends on browser storage. A manual replay entry and native onboarding remain future work.

## Tests and builds

365 automated tests passed with zero failures/skips, including 12 new API/browser-state cases. The separate targeted 12-case run also passed. These counts overlap. Checks cover eligibility, archived/foreign applications, persistence, concurrent retry, account ownership, deleted sessions, input bounds, origin, rate limits, safe failures, queued retries, stale replies, unavailable storage and cross-device refresh.

Final isolated NextAuth/MongoDB/Chrome acceptance passed all three steps and Back, final navigation, fresh-storage/relogin persistence, account switching, competing-feedback-dialog deferral, failed-save retry, Skip, Escape, keyboard focus and 390px layout. Desktop/mobile screenshots were reviewed. The final production Next.js build and scoped JavaScript/JSX lint passed. Native builds were outside this web delivery.

The first build lacked the required compile-time MONGODB_URI. A later build supplied a compile-only local URI and passed. The initial browser run found focus leaving the guide after the last button. A guide-specific focus loop fixed it. The second browser run timed out because of a malformed test selector. The corrected final browser run passed. Failed logs are retained alongside successful reruns.

The original workbook now contains 30 scoped milestones. JG-030 and Update Log row 41 were appended and the Gantt timeline extended through November 20. Status/date changes recalculate totals/bars. Saved-file verification retained prior cells/formulas, panes, merges, hyperlinks and conditional rules. Both changed workbook views were reviewed.
