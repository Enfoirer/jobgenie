# JG-032 Web getting-started replay

Implementation and local acceptance completed on 2026-11-28 (Asia/Shanghai). Implementation revision [f943187](https://github.com/Enfoirer/jobgenie/commit/f943187e4c72eaf56e44b2069731d1d634a3440f).

## Requirements and key decisions

The owner authorized a single web delivery for manual guide viewing. Add Getting started to dashboard navigation, available to accounts with applications and accounts that completed or skipped onboarding. Reuse the existing three steps, allow repeat viewing and closing, and use Add an application for the final manual action. The mobile navigation label is Guide, with the full accessible name and a 44px touch target. Read [behavior and acceptance](../../web-guide-replay-acceptance.md).

Keep completed/skipped outcomes and original timestamps authoritative. A known terminal choice needs no replay write. A first manual choice uses the existing atomic authenticated endpoint. Retain queued local choices and retry behavior. Status refreshes keep a manual guide open, while automatic eligibility continues to follow account state. Account-keyed lifecycles reject stale replies. Other dialogs prevent overlapping manual presentation. Closing returns keyboard focus to the navigation entry.
