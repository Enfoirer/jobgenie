# JG-031 Web empty-page guidance

Implementation and local acceptance completed on 2026-11-22 (Asia/Shanghai). Implementation revision [70d30ad](https://github.com/Enfoirer/jobgenie/commit/70d30addc6129fe351e906a2debc7ce3719e8bdd).

## Requirements and key decisions

The owner selected the next web onboarding task. Add actionable English guidance to empty application, calendar and file pages. The Job Board links to the existing Add Job page. The calendar explains how to save interview times and assessment deadlines and links to applications. The existing upload/drop area introduces the first resume and how to associate a submitted version with an application.

Use the current authenticated datasets. Archived-only applications, an empty archive and a rejected-only filtered view provide contextual recovery buttons. New-user guidance appears after a successful empty read. Loading, failure and retry states continue to explain their actual condition. A populated result restores its existing list/card interactions. Read [behavior and acceptance](../../web-empty-states-acceptance.md).

## Tests and builds
